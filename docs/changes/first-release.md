- Pokémon Card GB2 runs as a native app on Windows, macOS and Linux: the game's own program translated to native code, no emulator. It reads your own ROM, fills any window or screen with crisp scaling, follows any display's refresh rate, and sleeps between frames for very little battery use. Battery saves work with emulator `.sav` files; save states, screenshots, gamepads, pause and fast-forward are built in.
